尖塔开荒手册

Switch 版 · 卡牌译名以游戏内实际显示为准，按效果识别

三条铁律

1. 这不是收集游戏，是删牌游戏

目标卡组 20 张以内，15 张是神仙局。每拿一张牌问自己："抽到它我开心吗？" —— 犹豫就是不要。

2. 商店第一优先级是删牌

见到「移除卡牌」就买。删除顺序：先删基础打击，后删防御。把 5 张打击砍到 2 张，卡组立刻脱胎换骨。

3. 血量是资源，不是命

血可以换遗物、换升级、换精英怪。血量低于 50%-60% 才睡觉，否则一律升级卡牌。升级只给最常打的那张牌。

地图与战斗

  • 第一层尽量打 2 个精英怪 —— 遗物是滚雪球的唯一来源。
  • 问号事件上层多走、下层少走，第三层事件大多是坑。
  • 路线提前看整张图：精英多 + 篝火位置合适 + 商店在打完精英之后。
  • 敌人头顶的意图图标必看：攻击就防御，格挡/强化就全力输出。
  • 能这回合杀掉就别防御，多拖一轮就多吃一轮伤害。
  • 药水别囤，Boss 战和精英战直接用掉。

新手五个坑

坑为什么
见牌就拿卡组 40 张，永远抽不到关键牌
升级没用的牌升级只给核心牌
套路摇摆力量流混中毒流 = 两套都不成型，第一层末必须定方向
忽视消耗（Exhaust）牌打完就消失的牌是"临时增益"，前期非常强
拿太多 3 费大牌起手抽到就是卡手，卡手一次可能就是死

角色上手顺序

顺序角色理由
1战士自带回血，容错最高
2静默猎手中毒/弃牌思路清晰，学会"精简"的价值
3机器人球位机制绕，卡组要求高
4观者上限最高，姿态切换反直觉

先把每个角色通关一次（A0），再考虑爬 ascension 难度。

第一层生存模板

第一层的唯一目标：活到 Boss，并且卡组别变胖。不是"打赢每一场"，是"用最少的代价换到最多的资源"。

标准时间线

阶段做什么关键点
1. 前 3 场
普通战斗		 唯一目的：补 2-3 张输出牌 见到优质攻击牌就拿。输出不够绝对不要进精英
2. 第一个商店 第一件事：删 1 张打击 优先级：删牌 > 关键牌 > 遗物 > 药水
3. 第一个精英 条件：血量 ≥ 70% 且已有 2 张新攻击牌 带一瓶药水再进。第一层精英平均要掉 20-30 血，把它当"花血买遗物"
4. 篝火 血 < 50%（战士）/ < 60%（其他角色）睡觉，否则升级 只升级核心牌，别升级"以后会用到"的牌
5. Boss 前 留一个篝火升级核心牌，药水补齐 至少 50% 血进 Boss，低于这个数先睡觉

打 Boss 前，卡组应该长这样（自检清单）

  • 卡组 12-18 张（起手 10-12 张 + 3-6 张新牌）
  • 已经删掉 1-2 张打击
  • 拿到 至少 1 个精英遗物
  • 有 至少 1 张能打的输出牌（AOE 或高效单卡）
  • 核心牌已升级 1-2 张

上面五条里有三条没达成，说明这局第一层打得太保守 —— 精英怪打少了。

精英怪应对（新手死得最多的地方）

精英怪必掉遗物 + 更多金币，是必须打的；但每个精英都有"打法"，硬莽就是送。以下讲机制与破解思路，具体数值以游戏内为准。

商店：钱怎么花

优先级（从上到下）

顺序买什么说明
1移除卡牌几乎永远最优。越早删越便宜（每次删完价格会涨），所以第一个商店就动手
2核心牌碎片整理、催化剂、极限突破、回响形态、Rushdown 这类"一套路就靠它"的牌，看到直接买
3强力遗物只在钱多的时候买。遗物会随精英怪掉落，不用抢
4药水只在打 Boss / 精英之前买，且只买针对性的（回血、格挡、爆发）
5普通攻击/技能牌基本不买。商店里"看起来不错"的牌，90% 都是让你卡组变胖的陷阱

金币管理

  • 至少留够一次删牌的钱再考虑别的消费。
  • 删牌服务不是每个商店都有 —— 有就优先用掉。
  • 遗物"买得起但很贵"时问自己：这笔钱够不够删两张牌？删牌通常更值。

篝火：睡觉还是升级

情况选择
血量低于安全线
（战士 50%，其他 60%）		睡觉
血量健康，有核心牌没升级升级（只升核心牌）
血量健康，核心牌都升过了升级第二常用的那张牌，或者睡觉攒血给下一场精英
Boss 前的最后一个篝火几乎总是升级（除非血量已经危险到打不过）

记住：升级只能给"你每局都会打很多次"的那张牌。升级一张一局只打一次的牌 = 白给。

宝箱与问号事件

宝箱

  • 普通宝箱直接开 —— 免费遗物，没有任何理由不开。
  • 宝箱有概率是陷阱（需要钥匙等特殊道具），拿不到就算了，不要为了它改路线。

问号事件的通用规则

  • 上层多走、下层少走 —— 第一层事件收益好，第三层事件大多是坑。
  • 看到"支付生命换 X"的选项：血量 > 70% 才考虑，否则一律选保守项。
  • 看到"遗物 vs 回血"：血量安全拿遗物，血量危险拿回血。活着才有输出。
  • 遇到"金神像"类（拿了会触发陷阱掉血）：血量够就拿，遗物价值远高于那点血。
  • 不确定就选"离开 / 什么都不做" —— 不亏就是赚，这游戏里"错过收益"远没有"踩坑掉血"致命。

A 级 —— 强，但要看套路

  • 红骷髅（低血 +力量）—— 战士/敢卖血的角色神级
  • 符文立方体（受伤抽牌）—— 配合自伤流
  • 青铜鳞片 / 自成型黏土 —— 反伤与挨打收益，配合高频率受击
  • 日晷 / 墨水瓶 / 沙漏 —— 过牌与循环类，卡组薄时收益大
  • 各类 +力量 / +敏捷 / +聚焦 的专属遗物 —— 对应角色一律拿

规则很简单：Boss 遗物给的都是 +1 能量这种大收益，代价也同等巨大。新手优先选"没有副作用"的那几个。

战士 Ironclad

自带「燃烧之血」，每场战斗结束回 6 血 —— 全游戏最高容错，可以放心用血换资源。

三条路

套路核心难度
力量流 推荐+力量牌（激怒/恶魔形态/极限突破）+ 重刃（力量加成×3）低，最稳
格挡流壁垒（格挡不清空）+ 肉搏（伤害=格挡）中
消耗流腐化（技能 0 费且消耗）+ 无痛/黑暗拥抱高，上限最高

拿牌

必拿
  • 猛击 Bash（起手自带，全程最该升级）
  • 激怒 / 恶魔形态 / 弱点侦查
  • 极限突破（力量翻倍，胜利开关）
  • 重刃（力量流输出终端）
  • 不以为意（8 格挡 + 抽 1）
  • 痛击无视（巨量格挡，救命）
  • 旋风斩（AOE + 配力量）
  • 收割者（伤害回血）
  • 腐化（看到就拿）
陷阱，别拿
  • 完美打击（需要一堆打击，反精简）
  • Clash（手上有技能牌就打不出）
  • 狂暴 Rampage（需要循环）
  • 灼热打击（吃光篝火资源）
  • 所有 3 费大牌（巨力挥舞等）

删牌 / 篝火

  • 商店前三次花钱全删打击，最后才动防御。
  • 篝火：血 < 50% 睡觉，否则升级。升级顺序：猛击 → 重刃 → 旋风斩 / 不以为意。

遗物

强：血瓶、鸟面瓮（打技能回血）、钢笔尖、苦无/手里剑/折扇（配旋风斩）、符文立方体（受伤抽牌）、红骷髅（血低 +力量）、肉骨头。

Boss 遗物：咖啡壶（+1 费不睡觉）对战士友好；天鹅绒颈链 别选（废掉多段流）；痛苦印记（+1 费但拿诅咒）战士能消化，可拿。

三层节奏

  • 一层：补 3-4 张高质量攻击牌，打满 2 个精英。
  • 二层：必须备 AOE，套路定型。
  • 三层：补防御与稳定性，只有输出会被拖死。

一句话：删光打击 → 堆力量 → 猛击上易伤 → 重刃收人头。

静默猎手 The Silent

没有自带回血。血量是纯消耗品 —— 这是新手打猎手死得比战士快得多的头号原因。起手 12 张牌，起手输出比战士还弱，但过牌能力全游戏最强。

  • 剧毒烟雾（第一优先升级）

陷阱，别拿
  • 大结局（需整套卡组围绕它）
  • 千刃（要好牌循环才起效）

删牌 / 篝火（跟战士不一样）

  • 第一层别急着删光打击 —— 猎手起手输出太弱，先拿 2-3 张攻击牌（冲刺、淬毒之刃）再删。
  • 篝火：血 < 60% 睡觉（比战士保守）。升级顺序：剧毒烟雾 → 中和 → 冲刺 → 催化剂。

遗物

强：苦无 / 手里剑 / 折扇（多段攻击多）、鸟面瓮（唯一稳定回血来源之一）、冰淇淋、符文金字塔、坚韧绷带 / 手镯类（弃牌流）、赌徒筹码。

坑：咖啡壶（不能睡觉）尽量别选；天鹅绒颈链废掉弃牌流；蛇眼新手先别碰。

三层节奏

  • 一层（最难）：先补输出，能打 1-2 个精英就好，别贪。
  • 二层：中毒流发力，必须有 AOE。
  • 三层：补防御，猎手后期不缺伤害，缺的是活下来。

贯穿全程：猎手只够撑 2-3 次失误，不确定就防御。战士可以莽，猎手不行。

机器人 Defect

开局遗物：战斗开始时自动引导 1 个闪电球。理解门槛最高，成型后最省心。

「球」机制 —— 必须先懂

球作用
闪电球激发时打随机敌人 → 输出
冰霜球激发时给格挡 → 机器人主要防御手段
黑暗球自己累积伤害，激发时一次性爆发 → 后期核弹
等离子球激发时给能量 → 费用引擎
  • 球位默认 3 个。引导新球时最老的球被挤出去并自动激发 —— "用新球把冰霜球挤出来换格挡"是核心高级技巧。
  • 聚焦（Focus）让所有球数值变强，是最重要的属性。碎片整理（+聚焦）与电容器（+球位）是两根支柱。
  • 冰霜球被挤出去 = 免费格挡，所以机器人不太需要防御牌。

四条路

套路核心
冰霜防御流 推荐冰川（2 冰霜 + 格挡）+ 碎片整理 + 电容器，站得住慢慢磨
闪电爆发流电动力学（闪电打全体）+ 球状闪电 + 聚焦，二层清群效率第一
0 费流爪击 + 合众为一（0 费攻击收回手牌），一回合打十几张
回响形态流每回合第一张牌打两次，上限最高，但要薄卡组

拿牌

必拿
  • 自我修复（战斗结束回血，机器人的命根子）
  • 碎片整理（+聚焦，第一优先升级）
  • 电容器（+球位，质变）
  • 冰川（格挡 + 2 冰霜）
  • 电动力学（二层必备 AOE）
  • 球状闪电 / 寒流
  • 回响形态（见到就拿）
  • 递归（重新激发并回填一个球）
强，看情况 / 别乱拿
  • 偏见认知（聚焦暴涨但每回合掉 1 聚焦，需人工制品或橙色药丸抵消）
  • 核心冲击（打伤 + 人工制品）
  • 蒸汽屏障 / 自动护盾 / 缓冲 / 力场
  • 分离（一次激发所有球换牌和能量）
  • 陨石打击等 5 费大牌（没费用引擎就卡手）
  • 混沌、彩虹（随机引导球）
  • 创意 AI（污染卡组，跟精简死磕）
  • 只拿 1 张爪击（要么不玩，要么 3 张以上）

为什么机器人最需要精简

它比任何角色都依赖那几张关键牌（碎片整理、电容器、回响形态）。卡组厚 = 抽不到关键牌 = 球全是弱鸡。目标 15-20 张。先删打击（机器人的打击完全没用），防御可留几张。篝火顺序：碎片整理 → 冰川 → 自我修复 → 递归。血 < 60% 睡觉。

遗物

强：符文金字塔（0 费流/回响流极强）、冰淇淋、所有加球位/加聚焦的专属遗物、鸟面瓮、插入器（每两回合自动引导一个球，专属强力 Boss 遗物）。

坑：天鹅绒颈链 千万别选（废掉 0 费流与回响流）；蛇眼打乱高费关键牌；咖啡壶有自我修复时可接受。

三层节奏

  • 一层：起手很弱（电击只有 3 伤），先补 2-3 张攻击牌再打精英。
  • 二层：拿到电动力学就起飞，同时补齐冰霜体系。
  • 三层：4-5 个冰霜球每回合自动十几格挡，稳如老狗；再考虑黑暗球/回响爆发。

一句话：堆聚焦 → 铺满冰霜站住 → 用新球挤出旧球当输出/格挡 → 回响形态收尾。

观者 Watcher

上限天花板，也是最易玩崩的角色。双刃剑全游戏最锋利。起手仅 4 打击 4 防御，是四人中最精简的。

姿态机制

姿态效果关键
平静 Calm本身无效果退出平静时获得 2 能量 —— 永动机
愤怒 Wrath造成伤害 ×2受到伤害也 ×2
神格 Divinity伤害 ×3靠真言攒够层数进入，后期核弹

核心循环：警觉（进平静）→ 下回合爆发（进愤怒，回 2 能量）→ 双倍伤害 → 再回平静。
注意是"退出平静"才给能量，反过来什么都没有。两张牌都升级（费用降为 1）后，这个循环完全免费。

愤怒是双刃剑（最容易死在这里）

  • 进愤怒前先看敌人意图：它打 15，愤怒下就是 30。要么秒它，要么先铺格挡。
  • 别在打不死敌人的时候留在愤怒里结束回合，切回平静没惩罚（只是少拿 2 能量）。
  • 「空拳 / 空身 / 空心」这类退出姿态的牌是救命绳，身上至少留一张。

拿牌

必拿
  • Rushdown（进愤怒抽 2 张，引擎核心）
  • 连击 Flurry of Blows（0 费，每次切姿态从弃牌堆回手）
  • 心灵堡垒（切姿态获得格挡，唯一持续防御）
  • 空拳 / 空身 / 空心（退出姿态）
  • 无畏（敌人是攻击意图则进平静）
  • 攀手（攻击时获得格挡）
  • 多段攻击牌（愤怒下收益翻倍）
  • Vault（直接多一个回合）
新手别碰
  • 整套真言/神格流（成型太慢，三层前基本空过）
  • 欧米茄（慢到离谱，纯娱乐）
  • 保留类大牌（Windmill Strike、Perseverance 占手牌）
  • 弑神 Blasphemy（下回合你会死，只在能这回合结束战斗时用）

吃操作暴怒 Tantrum（进愤怒并把一张自己洗进弃牌堆，无限流关键）、内在平静、真言积累牌。

卡组要薄到变态

理想卡组 10-15 张，全游戏最薄。删打击 > 删防御；商店前三次全删打击。篝火升级顺序：爆发 → 警觉 → 心灵堡垒 → 连击（前两张升级后整个角色脱胎换骨）。

占卜（Scry）

看抽牌堆顶几张牌并弃掉不要的 —— 比"抽牌"更精细的过滤。有占卜牌（切断命运、第三只眼）优先拿，配「Nirvana」（占卜时获得格挡）和观者占卜遗物极强。

遗物

强：苦无 / 手里剑 / 折扇（多段快速叠属性）、冰淇淋（观者能量溢出多）、符文金字塔、所有占卜/姿态相关专属遗物。

坑：天鹅绒颈链 绝对别选（废掉无限连与连击流）；蛇眼慎选。

一句话：薄卡组 → 警觉/爆发双升级 → 平静进、愤怒出白嫖能量 → 双倍伤害收割 → 别在愤怒里挨打。

Boss 速查

Boss机制 / 威胁对策
六火鬼
第一层		 攻击伤害逐回合递增，拖越久越痛 速杀，别拖。力量流 / 愤怒姿态正好克制；中毒流无视它的高攻
史莱姆老大

守护者

冠军
第二层		 血量掉到一半进入狂暴，爆发极高 提前攒资源，半血那一刻一波带走。战士：攒力量 + 重刃；观者：愤怒一波；机器人：铺满冰霜硬吃

心态

前 10-20 局死掉都是正常的。这游戏的乐趣在于"下一次我会更聪明" —— 等你第一次通关，会发现前面所有看似正确的直觉（拿光所有牌、死守血量）几乎都是错的。

组卡器（点选，免打字）

选角色 → 点牌加卡 → 填入下方诊断。牌库收的是常用牌，没有的牌直接在下面的文本框里补写（手机键盘的语音输入念牌名也很快）。

卡组诊断器

把你的卡组一行一张粘进来（可以写"打击 x5"或只写牌名），它会告诉你卡组有什么问题。纯本地运算，不联网。

死亡复盘

选一下你这局是怎么死的，反推最可能的原因。适合死得莫名其妙的时候对照。
